Source Connectors

Four distinct ingestion patterns — each with its own transport, failure modes, and landing format.

streaming

📡 Kafka Transactions

Point-of-sale style events produced to a real managed Apache Kafka 4.1 cluster (Aiven free tier) over SASL_SSL using the native librdkafka client, drained to bronze partitions by the consumer step. Falls back to a local file broker for offline dev.

batch files

📁 Finance CSV/Excel

Budget workbooks dropped by the finance team — schema-detected, normalized, and landed as typed records with source lineage preserved.

API sync

🏢 SharePoint / MS Graph

Department and GL master data synced through Microsoft Graph client-credentials flow (or local export folders), deduplicated by natural key.

unstructured → OCR

🧾 Vendor Invoices

Scanned invoice PNG/JPGs pass through RapidOCR/Tesseract; regex field extraction pulls invoice number, dates, totals, and tax into structured JSON.

tool · text-to-sql

Schema-aware SQL generation

The agent receives the full silver/gold schema, emits SELECT-only DuckDB SQL, self-repairs on execution errors, enforces LIMITs, and shows the query it ran.

tool · forecasting

Statistical planning engine

"Forecast revenue for Q4" routes to Holt-Winters damped trend (Prophet when available) over monthly aggregates, rendered with confidence bands.

guardrails

Read-only by construction

Keyword blocklist, single-statement enforcement, allowlisted tables, LIMIT clamping — the analyst can read your numbers, never touch your data.
